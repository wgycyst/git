# 参数与故障排查

## 完整参数表

| 参数 | 默认 | 作用与调整建议 |
| --- | --- | --- |
| `--auto-crop` | 关 | 自动找纸张四角做透视校正。照片里有桌子背景时必开；检测失败会回退为原图 |
| `--corners x1,y1,...` | 无 | 手动给纸张四角（原图像素，顺序 左上/右上/右下/左下）。自动裁切不准时用 |
| `--trim N` | 自动 | 校正后裁掉 N 像素纸张边缘。默认校正过就裁 8，仍看到图框线就加到 20~30 |
| `--simplify` | 2.5 | 折线简化容差（像素）。线太碎→4~6；拐角被削圆→1~1.5 |
| `--min-len` | 25 | 丢弃短于该长度的笔画（像素）。噪点碎线多→40~60；小符号被丢掉→10 |
| `--min-area` | 12 | 去斑：小于该面积的墨点丢掉。纸张脏、麻点多→30~60 |
| `--ortho` | 0 | 把偏离水平/垂直不超过 N 度的线段拉直。建筑/管线/平面图用 2；曲线图保持 0 |
| `--mode` | trace | `trace` 输出多段线（保留圆弧形状）；`line` 每段输出 LINE（CAD 里好编辑） |
| `--close-tol` | 3.0 | 首尾点距离小于该值算闭合（像素）。矩形老是没闭合→调到 5~8 |
| `--max-dim` | 2200 | 处理分辨率上限，长边超过就缩放。线条细节丢失→3000；慢→1500 |
| `--invert` | auto | 深色纸白笔迹时用 `yes`；一般不用管 |
| `--ref x1,y1,x2,y2` + `--ref-mm` | 无 | 用两个参照点标定实际尺寸（坐标是预览图/工作图的像素坐标） |
| `--width-mm` | 无 | 另一条标定路径：整张纸的实宽（mm） |
| `--frame` | 关 | 额外画一个原图范围的边框（图层 SKETCH_FRAME） |
| `--grid` / `--grid-step` | 关 / 100 | 预览图上画带坐标标注的网格，用来读参照点像素 |
| `--json` | 无 | 额外导出顶点数据，便于后续按尺寸重建或二次处理 |

## 常见问题

**纸张边缘被描成一圈线**
自动校正后仍有残留 → 加 `--trim 20`。若照片里纸张没铺平、有卷边，先重拍。

**笔迹断裂、一笔变好几段**
毛笔/铅笔笔迹浅导致二值化断点 → `--min-area 6 --min-len 10`，并考虑提高对比度重拍。轻微断裂不影响描图使用。

**线太碎、顶点太多**
`--simplify 4`；建筑类图形再加 `--mode line --ortho 2`。

**整张图糊成一团 / 出现大片黑块**
照片阴影过重或反光 → 重拍（避开顶光正对、避开窗反光）；也可先 `--auto-crop` 裁掉背景再看。

**DXF 在 CAD 里打开看不见东西**
一般是视图问题：输入 `ZOOM` → `E`（范围缩放）；再检查图层 `SKETCH` 是否被关闭或冻结。

**尺寸差 10 倍或 1000 倍**
`--ref-mm` 单位是毫米；英寸/厘米要换算成毫米再传。

**控制台里中文路径显示成乱码**
只是显示问题（文件本身正常）。跑脚本前先设 `PYTHONIOENCODING=utf-8`（Windows PowerShell：`$env:PYTHONIOENCODING = 'utf-8'`）。

**找不到带依赖的 Python**
先跑 `scripts/check_env.py` 定位。常见位置：当前 `python`、`py -3`、Anaconda/Miniconda、其他软件自带的 Python（如 ComfyUI 的 `python/python.exe`）。**不要为了这个技能重装或新建大环境**；确实没有就 `pip install -r requirements.txt`（先征得用户同意）。

**自动转换工具在 CAD 里被许可/弹窗拦住**
有些 CAD 的批处理控制台在无人值守下会因许可弹窗失败。此时退回“先生成 DXF → 在 CAD 里打开 → 另存 DWG”的手动一步，不要反复重试。

**不想要“描线”，我要横平竖直、带尺寸的正式图**
那不是描线能做的事：请按用户给出的尺寸**参数化重建**（技能说明里有判断标准），本技能的 `dxfout.py`（DXF 写入）与 `dxf_check.py`（校验）可以复用。

## 拍图要求（给用户的建议）

- 白纸铺平、无卷边；四角都入镜，留一点背景边；
- 手机尽量正对纸面拍，不要大角度斜拍；
- 光线均匀，避免手影、窗反光、顶灯直射造成亮斑；
- 笔道用深色笔（黑/蓝），一笔写清楚，避免反复描粗；
- 需要算量时，草图上写清至少一个真实尺寸（或事后口述）。

## 安装位置与卸载

- 技能本体：`$CODEX_HOME/skills/sketch-to-cad`（Windows 默认 `%USERPROFILE%\.codex\skills\sketch-to-cad`）；删除该目录即卸载技能。
- AutoCAD 辅助工具（可选）：把 `assets/autocad/sketch-to-cad.lsp` 放到 AutoCAD 的 Support 目录，随图加载或在 CAD 里 `APPLOAD`。想回滚就删除该 lsp（若改过 `acaddoc.lsp`，把新增的那一行去掉即可），不影响任何图纸与设置。
- 自检样例：`assets/sample/hand_sketch_sample.jpg`（可用 `python assets/sample/make_sample.py` 重新生成），环境变动后跑一次确认链路仍正常。
